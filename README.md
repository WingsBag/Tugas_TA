# Game Puzzle 2D Top-Down - TA SMK

## Deskripsi
Game ini adalah game puzzle 2D dengan sudut pandang top-down yang menggunakan **grid system**.  
Pemain menggerakkan karakter di dalam grid untuk menyelesaikan puzzle di setiap level.  
Game dibuat menggunakan **Unity 2D** untuk memenuhi tugas akhir (TA) SMK jurusan Rekayasa Perangkat Lunak.

## Fitur
- Pergerakan player berbasis grid (WASD)
- Player hanya bisa bergerak di tile yang tidak ditempati wall
- Menyimpan progres permainan lokal
- Beberapa level puzzle sederhana

## Cara Menjalankan
1. Clone repository ini
2. Buka di **Unity 2021.3+** (2D Core Template)
3. Buka scene `Level01`
4. Tekan **Play** dan gunakan **WASD** untuk menggerakkan player

## Lisensi Asset
- Semua asset yang digunakan adalah **free asset untuk keperluan pendidikan**  
- Fokus penilaian: **logika dan sistem game**, bukan artwork

## Catatan
- Game **offline**, singleplayer
- Grid dan wall menggunakan Tilemap
- Player Rigidbody2D body type kinematic, Gravity = 0
